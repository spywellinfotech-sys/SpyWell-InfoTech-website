NFC Visiting Card: tap a tag, your card opens

Write your LiveCard link onto an inexpensive NFC tag or card from inside the app. When someone taps it with their phone, your live card opens, and you can see how many taps came from NFC.

NFC टैग/कार्ड पर अपना LiveCard लिंक लिखिए। सामने वाला फ़ोन छुआए तो आपका कार्ड खुल जाए।
Start free

What you get

  • Write the link to an NFC tag from the app on supported Android phones
  • Works with common NTAG213 tags
  • NFC taps are counted separately in insights
  • QR code as a backup for phones without NFC
  • Update the card without rewriting the tag

How to get started

  1. Open My card and tap the NFC button
  2. Hold a blank NFC tag near the back of your phone
  3. Share: anyone tapping the tag opens your card

Frequently asked questions

Which phones can write NFC tags?

Android phones with NFC using Chrome. iPhones can read tags but writing is done from Android.

Which tags work?

Common NTAG213 tags work well.

If I change my details, do I rewrite the tag?

No. The tag holds your link, which always shows the latest card.

What if the other phone has no NFC?

Show the QR code instead.
